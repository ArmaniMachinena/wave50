# Wave50

Детектор эпидемий: дашборд на одну страницу с вращающимся глобусом, индексом риска 1–50 и лентой новостей.
Закрытая демо-версия: страница, данные и исходники зашифрованы паролем.

- `source.enc` — зашифрованные исходники страницы и сборщика.
- Сборщик запускается GitHub Actions раз в 3 часа и пишет зашифрованные данные в ветку `data`. Нужен секрет `WAVE50_PASSWORD`.
